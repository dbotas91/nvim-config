# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

# Dário's LazyVim configuration

## Requirements

- Neovim >= 0.11
- Git
- Ripgrep
- fd
- Node.js
- Python
- LazyVim

## Install

git clone <https://github.com/dbotas91/nvim-config> ~/.config/nvim

## First run

:Lazy sync
